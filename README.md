💳 Razorpay Clone – Frontend UI (React + Tailwind CSS)
🧠 Overview

A frontend clone of Razorpay built using React.js and Tailwind CSS, focused purely on design, transitions, and responsiveness.
This project replicates Razorpay’s clean fintech aesthetic with modern layout, gradient effects, and smooth scroll animations.

🎯 Built to practice UI structuring, CSS mastery, and animation logic — a perfect mini project for portfolio display.

🚀 Features

💎 Fully responsive Razorpay-like homepage

🎨 Built with Tailwind CSS utility classes

⚡ Smooth animations using Framer Motion

🧩 Modular & reusable React components

🪄 Interactive hover transitions and CTA buttons

🖥️ Clean layout inspired by the official Razorpay website

🧠 Tech Stack
Category	Technology
Frontend	React.js
Styling	Tailwind CSS
Animations	Framer Motion
Build Tool	Vite or CRA (as used)
⚙️ Setup Instructions
# Clone the repository
git clone https://github.com/<your-username>/razorpay-clone-frontend.git

# Move into the project folder
cd razorpay-clone-frontend

# Install dependencies
npm install

# Run the app
npm run dev


Then open 👉 http://localhost:5173/
 (or your default port) in the browser.
